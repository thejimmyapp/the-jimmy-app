# Internal specimen workbench

Competitor reference lives ONLY under `docs/specimens/` (internal); `frontend/public/blocks/` holds ONLY our own components.

These captures are research references and must not be copied into public assets or application components. Reimplement useful behavior with project-owned markup, styling, and code.

## Archived reference annotations

- **14 · Analysis module** — [Lichess Crazyhouse analysis](https://lichess.org/analysis/crazyhouse). Reference lesson: modular stacking of pockets, engine state, controls, content, and navigation beside the primary board.
- **15 · Notification settings** — [Chess.com notification help](https://support.chess.com/en/articles/8618508-how-do-i-manage-my-notifications). Reference lesson: collapsible categories, global and per-event toggles, and explicit delivery channels.
- **16 · Typography hierarchy** — [Lichess About](https://lichess.org/about). Reference lesson: restrained sentence-case H1/H2 hierarchy with generous content spacing.
- **17 · Archive favorites rows** — [Chess.com favorites archive](https://www.chess.com/member/fearingforfreddy/games?activeTab=favorites). Reference lesson: compact row anatomy combining players, results, actions, move count, date, bookmark, and selection state.
- **18 · Player stats table** — [Chess.com member stats](https://www.chess.com/member/fearingforfreddy/stats). Reference lesson: dense statistics, rating deltas, disclosure, and visible-but-locked depth.
- **19–20 · Player clocks** — [Chess.com game analysis](https://www.chess.com/analysis/game/live/172758001776/analysis). Reference lesson: paired inactive/dimmed and active/bright clock states for turn visibility.
- **21 · Analysis dock** — [Chess.com game analysis](https://www.chess.com/analysis/game/live/172758001776/analysis). Reference lesson: vertical ordering of engine lines, moves, classifications, timing, navigation, and actions.
- **22 · Position-bound comments** — [Lichess study overview](https://lichess.org/@/lichess/blog/study-chess-the-lichess-way/V0KrLSkA). Reference lesson: authored prose belongs to one position rather than an unanchored game note.
- **23 · Glyph picker** — [Lichess study overview](https://lichess.org/@/lichess/blog/study-chess-the-lichess-way/V0KrLSkA). Reference lesson: compact position annotation choices; the shipped picker is a project-owned implementation.
- **24 · Alternate continuations** — [Lichess study discussion](https://lichess.org/forum/lichess-feedback/showing-of-possible-options-gone-from-studies). Reference lesson: sibling variations branch from the current position and remain navigable.
- **25 · Coupled-board viewer** — [bmacho Bughouse Viewer](https://bmacho.github.io/bughouse-viewer/view.html?game_id=180616071971). Reference lesson: keep both boards, four players, clocks, pockets, navigation, address, variations, and position comments in one coupled context.

Detailed notes for specimens 17–21 remain in `CLAUDE-SPECIMENS-INDEX.md`; the annotation-code boundary is documented in `LICHESS-STUDY-ANNOTATION-AGPL-REFERENCE.md`.
